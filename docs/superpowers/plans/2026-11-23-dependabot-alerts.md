# Dependabot Alerts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close all 171 open Dependabot alerts (105 root, 66 legacy) without changing what either app does.

**Architecture:** Refresh both lockfiles inside their major versions, raise the floors of the direct dependencies
that have alerts, and replace the three legacy packages that have no patched release (`request` and `serve-favicon`
removed, `jade` swapped for `pug`). One pull request, one commit per app.

**Tech Stack:** npm 11, Next.js 16 / ESLint 9 (root), Express 4 / pug 3 on Node 18 (legacy).

**Spec:** `docs/superpowers/specs/2026-11-23-dependabot-alerts-design.md`

## Global Constraints

- No `npm audit fix --force`.
- No major upgrade that an alert does not require (eslint stays 9, typescript stays 5, express stays 4).
- No alert is dismissed.
- Root floors, exact: `next` `^16.4.6`, `eslint-config-next` `^16.4.6`, `axios` `^1.21.1`, `postcss` `^8.5.33`,
  `overrides.minimatch` `^11.0.1`.
- Legacy ranges, exact: `express` `^4.22.3`, `body-parser` `^1.20.9`, `cookie-parser` `^1.4.7`, `axios` `^1.21.1`,
  `pug` `^3.0.4`. `request`, `serve-favicon` and `jade` are removed.
- Every package in `legacy/package-lock.json` must accept Node 18.
- Added lines stay at 120 columns or fewer (the repository's PR gate).

## Review Focus

1. **ESLint plugins loading minimatch 11 through the override** (`eslint-plugin-import` was written for 3.x):
   `npm run lint` must exit 0 with the same output as before the change. Checked in Task 1.
2. **The home page under pug** (`script(async='' src=…)` without a comma, the `//if lt IE 9` block): `GET /` answers
   200 and its markup matches what jade renders today, apart from whitespace. Checked in Task 2.
3. **The error page under pug**: `GET /no-such-page` answers 404 with `Not Found` in the body, not a 500 from a
   missing template. Checked in Task 2.
4. **The page's Brent call after `updateBrentOil` is gone**: `GET /investing/brentOil?callback=x` still answers
   `x({})`. Checked in Task 2.
5. **A legacy dependency that needs a newer Node than the deploy uses**: no `engines.node` in
   `legacy/package-lock.json` excludes 18. Checked in Task 2.
